# CPR LLM Test — 账号对话测试插件

Codex Proxy RS（CPR）的独立管理插件 **`donzy.account-dialogue`**，当前版本 **v0.4.1**。支持指定账号、模型、思考等级和自定义问题，批量进行真实对话测试。

## 功能

- CPR 原生 UI 与浅色/深色主题，不修改宿主前端或放宽 iframe 隔离权限。
- 账号、模型勾选列表：搜索、多选、全选/取消全选；支持手动添加模型名。
- 多选思考等级，自动生成账号 × 模型 × 等级组合；默认全选，可逐项排除。
- 自定义问题预设：保存、新增、编辑、删除；持久化于插件私有状态，使用版本 CAS 防止并发覆盖。
- 并发默认 **10**，插件不设置数值上限；CPR、账号和上游容量限制仍然生效。
- 单项超时默认 **180 秒**，实际执行期限受 CPR 宿主约束，见下方限制。
- 支持开始、暂停、继续和取消待测任务；答案及安全错误直接显示在结果表最后一栏，可复制、查看详情、导出 JSON。
- 原生弹窗在插件的当前可见区域居中，而非整张长页面中央；长预设使用原生滚动组件。
- 无 Todo List 生成按钮、无 Token 上限配置，不发送 `max_output_tokens`。

## 安装

1. 从本仓库 **Releases** 下载 `donzy.account-dialogue-0.4.1-aarch64-unknown-linux-gnu.tar.gz` 及对应 `.sha256` 文件。
2. 核对 SHA256；不要解压重打包。
3. 在 CPR 原生插件管理中上传安装包，并启用该插件。
4. 从「插件 → 账号对话测试」打开页面。

**兼容性：** CPR `>=3.25.0, <4.0.0`；本次发行的二进制适用于 **Linux ARM64（aarch64）**，不是 Windows 或 x86_64 包。后端实际使用 `aarch64-unknown-linux-musl` 目标交叉编译；安装包文件名沿用 CPR 包命名约定，包清单标记 `linux/aarch64`。

插件使用 `trustedProcess` 运行时。仅安装你信任的插件发行包。

## 使用

1. 选择执行 Key，勾选账号和模型，多选思考等级。
2. 输入问题，或套用已保存预设。
3. 在自动生成的任务表中取消不需要的组合。每批最多 **500 个组合**。
4. 设置并发与超时，点击「开始测试」，核对提示后确认。
5. 保持页面打开以继续派发任务，在底部结果表查看答案。

`default` 不发送 `reasoning` 参数；其他等级原样发送，不保证所有模型都支持，也不自动降级。思考等级请求参数和上游回显不能证明模型内部实际思考强度。手动添加模型仍受真实权限、模型规则及可用性检查。

## 重要限制与安全行为

### 超时与并发

默认超时输入值为 **180 秒**，但当前 CPR 3.25.0 宿主管理调用最长为 **120 秒**。插件预留 8 秒收尾，当前有效测试期限最多约 **112 秒**，上游限制还可能使请求更早结束。页面明确显示配置值和有效期限，结果也记录二者。**此版本不宣称已支持实际等待满 180 秒。** 延长实际期限需要宿主提供相应支持，本插件不修改 CPR 本体、SDK 或宿主期限。

模型测试按所选并发进行批次派发，一个批次使用一个管理调用，避免每个模型独占一个页面管理请求。管理桥请求使用有界传输队列；它不是用户模型并发上限。宿主资源、Key、账号和上游的容量限制仍正常生效。设置很高的并发可能被宿主拒绝或产生容量错误，不会绕过这些限制。

### 指定账号与执行安全

- 使用原生 `host.model.execute_stream` 显式指定 Key ID、Provider 与 `account_id`，经过 CPR 正常权限、调度、预算和计费流程。
- 不读取原始账号凭据，不临时改账号组，不放宽模型白/黑名单，不换其他账号代测。
- 任务取消或暂停仅停止新的请求；已发送请求仍可能产生费用。
- 父调用中断时记录结果未知，不自动重发；重复提交已完成任务不会重复生成。
- 答案最多保留 **64 KiB**，超过明确标注截断；页面使用文本插值，不执行回答中的 HTML。
- 错误正文、凭据、headers 不透传到页面，显示安全分类。
- 账号核对读取精确请求 ID 的 CPR 原生日志；「主记录匹配」不等于尝试明细完整的审计。

### 状态生命周期

当前批次及答案存于插件进程内存。**插件重启、换版或停用会清空该内存缓存**；升级前请导出需要保留的结果，先停止新派发并等待在途请求结束。

问题预设存于 `prompt-presets/document`（schema 1），所有管理员共享，不写入账号或模型配置。预设最多 32 条，名称最多 64 字符，单问题最多 16 KiB，整个序列化文档最多 48 KiB；保存采用精确版本 CAS。编辑当前问题不会自动覆盖预设。

弹窗遮罩仍限于插件 iframe，不覆盖 CPR 的侧栏和页面标题。定位仅通过浏览器可见交集测量，不读取父文档或放宽 sandbox。

## 开发与构建

目录结构：

```text
backend/             Rust 插件后端
frontend/src/        Vue 3 页面及原生 UI 集成
frontend/vendor/     固定版本的官方 UI 包
vendor/              官方 gateway-plugin-sdk 源码与许可
web/                 已构建的 IIFE 页面资源
Scripts/             构建、IPC、UI 合同测试及本地模拟工具
```

需要 Node.js（本地验证版本 24）、Python 3、Rust（本地验证版本 1.99）及 `aarch64-unknown-linux-musl` target。

```powershell
npm --prefix frontend ci --ignore-scripts
rustup target add aarch64-unknown-linux-musl
python Scripts/build.py
cargo clippy --manifest-path backend/Cargo.toml --all-targets --locked -- -D warnings
```

构建运行 Vue/TypeScript 检查、Vite IIFE 打包、JS 语法检查、Rust 单测、真实插件进程 IPC 测试，再交叉编译、生成清单资源哈希、安装包及 SHA256。

v0.4.1 已通过 **35 项自动测试**（Rust 8、IPC 19、UI/组合逻辑 8），包含 10 个同时执行的模拟模型流、任务筛选、防重复、并发控制、暂停/取消、预设 CAS 和输入边界。

本地 UI 模拟：

```powershell
node Scripts/preview.mjs
```

访问 `http://127.0.0.1:18947`；支持 `state=empty/many/long/interactive`、`theme=light` 和 `/embedded` 沙箱定位回归页。默认只读；`interactive` 仅进行内存模拟，明确显示回执，**不连接真实模型上游或生产数据**。模拟脚本不进入插件安装包。
